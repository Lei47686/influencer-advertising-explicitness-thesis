# Research Materials for Master's Dissertation

This repository contains code, de-identified analysis data, and experimental materials associated with a Master's dissertation examining advertising explicitness in short-form influencer content.

## Repository Structure

- `study1/`: Study 1 AES code, documentation, and the location reserved for approved de-identified analysis data.
- `study2/`: placeholders for final experimental code, de-identified participant data, and stimulus-access information.
- `materials/`: supplementary reproducibility materials.

## Study 1

Study 1 examines the association between advertising explicitness and observed interaction rates in naturally occurring Douyin commercial videos. Advertising explicitness is operationalized using the Advertising Explicitness Score (AES), which combines multimodal visual and semantic scoring. The included implementation uses the final frozen V3 specification. The `study1/data/` directory is reserved for the final analysis-ready data after de-identification review.

## Study 2

Study 2 is a randomized between-subjects experiment comparing two conditions:

- High Integration
- Hard Sell

The design uses AI-generated matched stimuli, randomized condition assignment, and de-identified participant data. Stimulus links are provided below and in `study2/stimuli/README.md`. Final Study 2 code and data should be added only after alignment with the dissertation has been confirmed.

## Reproducibility Notes

- The repository corresponds to the final dissertation methodology.
- AES V3 parameters are frozen.
- Exact historical package versions used during initial development were not fully preserved.
- Therefore, the repository documents required software libraries and model specifications without inventing unrecoverable historical package versions.
